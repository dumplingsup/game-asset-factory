# v0.3 范围与样本事实

基于 v0.2.0 的同一工厂、CLI、角色插件、修订账本与 Godot Harness 增量开发。未修改原游戏、原本地工厂或冻结生成器。历史调查保留在 Git 与 research.json；当前技术结果见 [VALIDATION.md](VALIDATION.md)。

用户先选择狼／狐兽头双足角色，随后提供官方 KAI ZIP，并明确授权“以 KAI 为基础做真实装备／面部改造，单独记录新增内容”。据此采用真实派生样本，不再要求原下载本身具备全部缺项。

| 来源 | 实际已有内容 | 本轮处理 |
|---|---|---|
| KAI，Realidad Aumentada Empezando Desde Cero，CC-BY-4.0 | 单 Mesh、单材质、41 骨、蒙皮、8 个动作；护甲烘在身体上，无 Morph、无可拆装备 | 保留原件、骨架静止数据、权重、UV 和八个原动作曲线；规范前向，新增内容另记 |
| Kenney Mini Dungeon 2.0，CC0 | 实际 sword、spear、shield 网格及 colormap 纹理 | 配置尺寸与手部骨骼附件；相同真实材质去重，共享一套装备材质 |
| 本轮原创修改 | 原件中不存在 | 两个平滑面部 Shape Keys、一个表情动作、装备装配与耳尖局部改形；不称为原 KAI 功能 |
| Wolfman，Polygonal Mind，CC0 | 1 Mesh／1 材质、65 骨、16 个 Morph（15 个明显非零）、无动作 | 仅作为实际 Morph／稀疏格式补测件，不代替动画角色 E2E |

派生角色有 4 个真实 Mesh、2 个实际材质、41 骨、9 个动作、2 个有效面部目标。没有拆分身体凑 Mesh 数或复制材质凑计数。原护甲仍不可换装，本轮换装覆盖独立武器与盾牌，不声称完成服装重做。

## 已限定的实施内容

- 同一 Blender worker 导入、保存 .blend、导出并重新导入 GLB；保护原动作、UV、蒙皮、材质与纹理摘要。
- 显式 Morph 保留：稀疏 accessor、目标名称／数量／差分、weights 动画、Blender 双向几何对应、Godot 实际面部位移与供体权重对照。
- JSON 局部修改同时移动 Basis 与所有目标，保持目标相对差分；源修订、重建与 checkout 回滚。
- 装备组件清单保存真实节点、槽、骨骼、激活变换与默认状态。源变换保持可逆，运行时按可见性切换。
- 同一 Godot 检视器增加正背侧／面部近景、第三人称行走／攻击／换装，以及真实键鼠入口；不增加完整游戏。
- 兼容骨架动作库落盘后重新载入到造型修改版；骨架 rest/bind 签名必须匹配。跨骨架重定向未实现。
- 独立、非录像、非固定 FPS 的性能采样，记录机器、分辨率、帧时与渲染计数；不把视频帧率当性能。

## 验收边界

技术验收需要真实文件、真实 Blender/Godot/FFmpeg、完整日志、重建与负例。美术验收始终 `pending_human`，由人判断表情语义、轮廓、变形、装备握持、贴图和动作观感。

本轮没有自动绑定、任意 retarget、换装衣物蒙皮／布料、自动重拓扑、收费服务、多 Agent 框架、Mod Adapter 或完整游戏。第三人称只是资产检视，没有验证碰撞、命中、伤害或战斗玩法；攻击复用原 Punch 动作，不称为新制武器招式。

调查中未采用的 Buffedwolf／MeganTheFox 没有原动作；vrcfox 为 CC-BY-NC；同名 wolf.glb 的版权作者与 KAI 不符。未将这些候选冒充 KAI 或商业授权样本。逐件调查记录和哈希保留在 research.json；所有原始失败尝试本地留存。
